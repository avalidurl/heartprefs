# How to launch the HeartPrefs W3C Community Group (GOK-172)

Free, no fees. Verified against the W3C Community Group FAQ (2026-07-04).

## Steps

1. **W3C account** — create one at w3.org if you don't have it.
2. **Propose the group** — use "Create a Community Group": name **"HeartPrefs Community Group"**, short name e.g. `heartprefs`, description = the Mission/Scope from [`charter.md`](charter.md). (New-member proposals get a staff review within ~3 business days; existing members' proposals are announced immediately.)
3. **Gather 5 supporters** — the group is **auto-created ~1 business day after the fifth person clicks "Support this group."** This is the real gating step — line up five supporters before/at proposal time.
4. **Appoint Chair(s)** — Gökhan as initial Chair (co-Chairs welcome).
5. **Adopt the charter** — publish [`charter.md`](charter.md) (optional but recommended; the group can start work without it).
6. **Set up comms** — the W3C-provided mailing list + point the group at the `gokhan-vc/heartprefs` GitHub repo for issues/PRs.
7. **CLA/FSA** — participants agree to the **CLA** on joining; sign the **FSA** when publishing a final Community Group Report.

## Why this first

A W3C CG is a recognized standards body home. It (a) unlocks graduating the media type from the vendor tree (`application/vnd.heartprefs+json`) to the standards tree (`application/heartprefs+json`), and (b) gives HeartPrefs neutral governance — the "bank the moat, then donate the schema" endgame in the strategy note.
