# w3id.org/heartprefs

Permanent identifier namespace for **HeartPrefs** — an open, portable, signed matching-intent document for agent-mediated matching.

- Specification: <https://github.com/gokhan-vc/heartprefs>
- Schema `$id`: `https://w3id.org/heartprefs/0.1/schema.json`
- Maintainer / contact: Gökhan Turhan (Numetal) — <contact@gokhan.vc>
- License: CC-BY-4.0 (spec) / Apache-2.0 (SDK)

Redirects are defined in [`.htaccess`](.htaccess) (302, per w3id convention). The redirect target `<CANONICAL_SCHEMA_HOST>` must be set to the immutable host serving the schema before this is merged.
